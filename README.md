# 🏥 포항 바로닥터 (Pohang BaroDoctor)
> **공공데이터포털 실시간 응급의료 API & Gemini 3.6 Flash 기반 맞춤형 AI 병원 안내 서비스**

포항 시민과 한동대학교/양덕동 대학생 및 자취생들을 위해 갑작스러운 야간/휴일 질환(장염, 고열, 외상 등) 발생 시 **0-클릭 음성 대화**와 **공공데이터 실시간 응급실 가용병상 연동**, **네이버 지도 원터치 길찾기**를 지원하는 AI 의료 길잡이 서비스입니다.

---

## 🌟 주요 핵심 기능

1. 🤖 **Gemini 3.6 Flash 대화형 AI 트리이지**
   - 사용자가 겪는 증상(예: *"일요일 5시에 장염 걸렸어 어디 가야 해?"*)에 대해 따뜻한 공감과 의학적 행동 요령(수액 치료 권고, 긴급도 판단)을 실시간 생성.
2. 🟢 **공공데이터포털(국립중앙의료원) 실시간 응급병상 연동**
   - `getEmrrmRltmUsefulSckbdInfoInqire` API를 통해 포항시 5대 응급의료기관(좋은선린병원, 포항의료원, 세명기독병원, 포항성모병원, 에스포항병원)의 실시간 잔여 응급병상 및 소아응급 병상 수 표시.
3. 📍 **GPS 기반 최단거리 계산 & 정렬**
   - Haversine 알고리즘을 통한 실시간 거리(m/km) 및 차량/도보 소요 시간 계산.
   - `[⭐ 스마트 추천순]` 및 `[📍 가까운 거리순]` 실시간 정렬 토글.
4. 🗺️ **네이버 지도 원터치 다이렉트 연결**
   - 병원 카드의 `[🗺️ 네이버 지도에서 보기]` 버튼을 누르면 실제 네이버 지도 앱/웹으로 즉시 이동하여 길찾기 및 내비게이션 연결.
5. 🗓️ **휴일·야간 진료 필터 (공공데이터 원본 기반)**
   - E-Gen 요일별 진료시간을 그대로 사용해 `☀️ 일요일 진료(30곳)` / `🎌 공휴일 진료(89곳)` / `🌙 야간진료(7곳)` / `🚨 24시 응급실(5곳)` 필터 제공.
   - `🌙 달빛어린이병원`(야간·휴일 소아진료, 2곳) 배지 표시.
   - "오늘 진료 여부"는 저장값이 아니라 요청 시점에 요일별 진료시간에서 계산.
6. 🎤 **음성 인식 (Web Speech API + Gemini STT 백업)**
   - 타자 칠 기운이 없는 응급 상황에서도 마이크 버튼 하나로 음성 대화 지원.
7. 📢 **집단지성 사용자 제보 & 심사위원 데모 패널**
   - 실시간 병원 상태 제보 시스템 및 해커톤 시연용 관리자 토글 드로어 완비.

## 📊 공공데이터 출처 및 데이터 신뢰성 (Data Provenance)

'포항 바로닥터'는 대한민국 정부 공공데이터포털(data.go.kr) 및 보건의료 공공기관의 공식 등록 데이터를 기반으로 구축되었습니다.

| 공공데이터 명칭 | 제공 기관 | 활용 항목 및 역할 |
|---|---|---|
| **응급의료 실시간 가용병상 정보**<br/>(`getEmrrmRltmUsefulSckbdInfoInqire`) | 보건복지부 산하<br/>**국립중앙의료원 (NMC)** | 포항 5대 응급의료기관 실시간 응급실 잔여 병상(`hvec`) 및 소아응급 병상(`hv28`) 3분 주기 실시간 연동 |
| **전국 병·의원 및 약국 위치·진료시간 정보**<br/>(`getHsptlMdcncListInfoInqire`) | **국립중앙의료원 (E-Gen)** | 포항시 병의원 정식 기관명, 도로명 주소, 대표 전화번호, WGS84 GPS 좌표, 요일별(월~일/공휴일) 법정 진료시간 |
| **응급의료기관 지정 목록 정보**<br/>(`getEgytListInfoInqire`) | **국립중앙의료원 (NMC)** | 권역응급의료센터, 지역응급의료센터 지정 여부 및 등급 분류 |
| **달빛어린이병원 지정 현황** | **보건복지부** | 야간·휴일 소아청소년 외래 진료 지정기관 현황 배지 |
| **포항사랑상품권 가맹점 공개 데이터** | **포항시청** | 포항사랑카드(지역화폐) 결제 가능 병의원 가맹점 매핑 |

### 💳 지역 특화 데이터 매핑
- **포항사랑상품권(포항사랑카드) 결제 여부**: 포항시청 지역화폐 가맹점 공개 자료 및 상호명 매핑을 통해 병원별 결제 가능 여부를 안내합니다.
- **실시간 데이터 갱신**: 요일별 진료 여부는 단순 고정값이 아닌, 사용자 요청 시점의 실제 요일 및 법정 공휴일 시간을 기준으로 실시간 연산됩니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Backend**: Python 3.9+, Flask, Gunicorn, Requests, XMLtoDict
- **AI & LLM**: Google Gemini 3.6 Flash (`google-genai` SDK)
- **Open Data**: 국립중앙의료원 E-Gen 병의원 정보, 공공데이터포털 응급의료정보서비스 API
- **Frontend**: Vanilla HTML5/CSS3, JavaScript (Pretendard Font, Mobile-First Glassmorphism UI)
- **Map & Integration**: Naver Map / Kakao Map Web Integration

## 🚀 로컬 실행 방법

```bash
# 1. 가상환경 생성 및 활성화
python3 -m venv .venv
source .venv/bin/activate

# 2. 패키지 설치
pip install -r requirements.txt

# 3. 환경 변수(.env) 설정
GEMINI_API_KEY="your-gemini-api-key"
DATA_GO_KR_DECODING_KEY="your-data-go-kr-decoding-key"

# 4. 서버 실행
python app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속

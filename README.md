# 병원찾기서비스

포항시 응급의료기관을 **증상 + 원하는 날짜**만 말하면 찾아주는 챗봇 프로토타입.
"일요일 5시, 갑자기 장염에 걸렸는데 어디로 가야 하지?" 같은 상황을 위해 만들었어요.

## 문제 상황

주말·야간처럼 대부분의 병원/의원이 문을 닫는 시간대에 갑자기 아프면, 정작 지금 갈 수 있는 병원을 찾기가 어렵다.
→ 어디가 아픈지 + 언제 가고 싶은지 말하면, AI가 진료과목을 판단해서 포항시 내 갈만한 병원을 추천해준다.

## 주요 기능

- 💬 **챗봇 UI**: 카톡처럼 증상/날짜를 자연어로 입력
- 🩺 **증상 → 진료과 자동 분류**: 키워드 매칭 기반 (예: "배 아파요" → 내과)
- 📅 **날짜/요일 인식**: "오늘/내일/모레", "8월 14일", "일요일에" 등 자연어로 인식해 정확한 날짜 계산
- 🏥 **실제 공공데이터 기반 병원 목록**: 포항시(북구+남구) 응급의료기관 5곳, 등급·주소·전화번호 표시
- 🎤 **음성 입력(STT)**: 마이크로 말하면 텍스트로 변환
- 🔊 **음성 출력(TTS)**: 추천 결과를 음성으로 읽어줌 (시각장애인 등 접근성 고려)
- 📋 **주소 복사 버튼**, 📞 **전화 바로 걸기**

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 백엔드 | Flask (Python) |
| 병원 데이터 | [공공데이터포털](https://www.data.go.kr) — 국립중앙의료원 응급의료기관 정보 조회 서비스 |
| 음성 인식(STT) | Google Gemini API (`gemini-3.6-flash`) |
| 음성 합성(TTS) | Google Gemini API (`gemini-2.5-flash-preview-tts`) |
| 오디오 변환 | ffmpeg + pydub (브라우저 webm 녹음 → wav 변환) |
| 프런트엔드 | HTML/CSS/JS (프레임워크 없이 순수 구현) |

## 폴더 구조

```
app.py               # Flask 백엔드 — 병원 검색, 진료과 분류, 날짜 파싱, STT/TTS API
templates/index.html # 챗봇 화면 (말풍선 UI, 마이크/스피커 버튼)
requirements.txt      # 패키지 목록
.env                  # 실제 API 키 (로컬 전용, git 제외)
.env.example          # 키 템플릿 (이 파일만 git에 포함)
.gitignore
```

## 팀원 설치 가이드

### 1. 클론
```bash
git clone https://github.com/Shonny-cloud/-.git
cd -
```

### 2. 패키지 설치
```bash
pip install -r requirements.txt
```

### 3. ffmpeg 설치 (음성 기능에 필요)
Windows:
```bash
winget install --id=Gyan.FFmpeg -e
```
설치 후 터미널을 새로 열어야 PATH가 적용돼요.

### 4. `.env` 파일 만들기
```bash
cp .env.example .env
```
`.env`를 열고, **팀 카톡/디스코드로 전달받은 실제 키**를 채워넣으세요:
```
GEMINI_API_KEY=실제_키_값
DATA_GO_KR_DECODING_KEY=실제_키_값
```
⚠️ `.env`는 git에 올라가지 않아요(`.gitignore` 등록됨). **절대 커밋하지 마세요.**

- Gemini 키 발급: https://aistudio.google.com/apikey (무료)
- 공공데이터포털 키: [국립중앙의료원 응급의료기관 정보 조회 서비스](https://www.data.go.kr) 활용신청 후 마이페이지에서 확인

### 5. 실행
```bash
python app.py
```
`http://127.0.0.1:5000` 접속.

## 알려진 한계 (다음 개선 방향)

이 프로젝트는 프로토타입이라, 발표/제출 전에 아래 내용을 명시하거나 개선하면 좋아요.

- **진료과 태그는 하드코딩**: 공공데이터가 병원 등급(응급의료기관 종류)만 제공하고 진료과 정보는 없어서, `app.py`의 `HOSPITAL_META`에 임의로 채워넣은 값입니다. 실제 병원 정보와 다를 수 있어요.
- **증상 분류는 키워드 매칭**: 진짜 의학적 AI 판단이 아니라 단순 키워드 매칭(`SYMPTOM_RULES`)이라, 애매한 표현은 못 잡을 수 있어요.
- **실시간 병상 정보 아님**: "24시간 운영"은 응급의료기관으로 등록돼 있다는 정적 사실이고, 그 순간 실제로 수용 가능한지는 확인 안 됨. 공공데이터포털의 `getEmrrmRltmUsefulSckbdInfoInqire`(실시간 가용병상 조회) API로 업그레이드하면 개선 가능.
- **지역이 포항시 5개 병원으로 한정**: 다른 지역으로 넓히려면 `STAGE1`/`STAGE2_KEYWORD`뿐 아니라 `HOSPITAL_META`도 수동으로 채워야 함.
- **개발 서버 상태**: `app.run(debug=True)`는 로컬 테스트용. 실제 배포 시 `gunicorn`/`waitress` 같은 운영 서버로 교체 필요.
